# DevMart - 쇼핑몰 백엔드 & 풀스택 프로젝트

Spring Boot 기반 전자상거래 서비스 구현 프로젝트로, 회원·상품·주문·결제 등 핵심 기능과 관리자 페이지까지 백엔드와 프론트를 모두 직접 개발했습니다.  
진행 중인 기능도 포함되어 있으며, 실무 수준의 설계·구현·운영 경험을 반영했습니다.

---

## 기술 스택
- Language: Java 17
- Framework: Spring Boot 3.2.0, MyBatis 3.5.13
- Database: MySQL
- Frontend: Thymeleaf, Bootstrap, jQuery
- Build Tool: Maven
- Security: Spring Security, BCrypt
- 기타: AJAX, REST API, 로그 처리, 트랜잭션 관리

---

## 주요 구현 기능
- 회원 관리: 회원가입, 로그인, 마이페이지, 비밀번호 암호화
- 상품 관리: 상품 목록·상세 조회
- 장바구니 & 주문: 장바구니 담기/수정/삭제, 주문, 결제(모의)
- 관리자 페이지: 상품/회원/주문 관리 REST API
- 리뷰 & 문의(Q&A): CRUD, 별점, AJAX 연동
- 운영 안정성: 트랜잭션 처리, 예외 처리, 보안 강화

---

## 진행 상황
- 완료: 회원가입·로그인·암호화
- 진행중: 마이페이지 CRUD
- 완료: 장바구니 기능 및 AJAX 연동
- 진행중: 주문/결제 페이지 개발 (주문o 결제x)
- 완료: 관리자 페이지(상품/회원/주문 관리)
- 진행중: 리뷰/문의 기능 프론트 연동
- 완료: 보안(Spring Security), 로깅, 트랜잭션 처리
- 진행중: UI/UX 고도화, 통계/모니터링

---

## 차별화 포인트
- 실무 환경에서 사용하는 MyBatis 동적 SQL 및 페이징 최적화 적용
- 트랜잭션 롤백과 FK 제약 고려한 안전한 데이터 처리
- 백엔드-프론트 완전 분리 없이 Thymeleaf+AJAX 혼합 구조로 개발 속도와 유지보수성 확보
