# devMart 쇼핑몰

## 프로젝트 개요
Spring Boot 기반 쇼핑몰 프로젝트로, 회원·상품·주문·결제 등 전자상거래 핵심 기능을 백엔드와 프론트에서 모두 구현했습니다.

---

## 기술 스택
- Language: Java 17  
- Framework: Spring Boot 3.2.0, MyBatis 3.5.13  
- Database: MySQL  
- Frontend: Thymeleaf, Bootstrap, jQuery  
- Build Tool: Maven

---

## 주요 기능
- 회원 관리: 회원가입, 로그인, 마이페이지, 비밀번호 암호화(BCrypt)
- 상품 관리: 상품 목록·상세 조회
- 장바구니 & 주문: 장바구니 담기, 주문, 결제(모의)
- 관리자 기능: 상품·주문 관리 REST API
- 리뷰/문의(Q&A): CRUD 기능 (진행 예정)
- 기타: 트랜잭션 관리, 보안 설정, 로깅 처리

---

## 실행 방법
1. 필수 설치: JDK 17, MySQL
2. application.yml에서 DB 정보 확인/수정
3. DB 스키마 및 테이블 생성 (초기 SQL 제공)
4. 프로젝트 루트에서 명령 실행

   mvn clean install
   mvn spring-boot:run

5. 브라우저 접속: http://localhost:8080

---

- 로그인 화면
